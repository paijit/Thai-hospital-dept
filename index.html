ภาพรวม

ทำความเข้าใจวิกฤตหนี้โรงพยาบาล

โรงพยาบาลรัฐของไทยกำลังเผชิญวิกฤตการเงินที่รุนแรงขึ้น โรงพยาบาลหลายแห่งใช้จ่ายในการรักษาผู้ป่วยมากกว่างบประมาณที่ได้รับจากระบบหลักประกันสุขภาพ

งบประมาณไม่เพียงพอ

อัตราการเบิกจ่ายจากภาครัฐมักไม่เพียงพอต่อค่าใช้จ่ายจริงในการรักษา ทำให้โรงพยาบาลขาดทุนสะสมทุกปี

โครงการ 30 บาท

ระบบหลักประกันสุขภาพถ้วนหน้าให้บริการราคาย่อมเยา แต่มักเบิกจ่ายให้โรงพยาบาลต่ำกว่าต้นทุน โดยเฉพาะการรักษาที่ซับซ้อน

ค่าใช้จ่ายที่เพิ่มขึ้น

ค่าเวชภัณฑ์ ราคายา และค่าบำรุงรักษาอุปกรณ์การแพทย์เพิ่มขึ้นอย่างต่อเนื่อง สร้างภาระเพิ่มเติมต่องบประมาณโรงพยาบาล

โรงพยาบาลในชนบท

โรงพยาบาลในจังหวัดห่างไกลได้รับผลกระทบมากเป็นพิเศษ ต้องให้บริการประชากรจำนวนมากด้วยงบประมาณและทรัพยากรที่จำกัด

ข้อมูลและการวิเคราะห์

กราฟแสดงหนี้สินโรงพยาบาล

กราฟเชิงโต้ตอบแสดงการกระจายหนี้สินของโรงพยาบาลรัฐที่ได้รับผลกระทบมากที่สุดทั่วประเทศไทย

รายชื่อโรงพยาบาล

โรงพยาบาลที่มีหนี้สูงสุด

ดูรายชื่อโรงพยาบาลรัฐที่เผชิญกับปัญหาการเงินอย่างหนัก คลิกที่โรงพยาบาลเพื่อดูรายละเอียดและบริจาค

ร่วมสร้างความเปลี่ยนแปลง

บริจาคผ่าน QR Code

สแกน QR Code ด้วยแอปธนาคารของคุณเพื่อบริจาคโดยตรงสู่กองทุนช่วยเหลือโรงพยาบาล ทุกบาททุกสตางค์มีความหมาย โปรดตรวจสอบรายละเอียดเมื่อสแกน QR Code ว่าถูกต้องหรือไม่ก่อนทำการโอน

ℹ️

การบริจาคทำงานอย่างไร

QR Code เชื่อมต่อกับบัญชีพร้อมเพย์และบัญชีบริจาคอย่างเป็นทางการของโรงพยาบาล เงินบริจาคจะถูกส่งตรงไปยังกองทุนโรงพยาบาลเพื่อจัดซื้อเวชภัณฑ์ บำรุงรักษาอุปกรณ์ และดูแลผู้ป่วย การบริจาคทั้งหมดสามารถนำไปลดหย่อนภาษีได้ตามกฎหมายไทย
